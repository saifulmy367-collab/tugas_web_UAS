Tentang Kami

Informasi singkat mengenai website AuresaGlow.

AuresaGlow adalah website simulasi e-commerce produk skincare yang dibuat untuk memenuhi tugas Ujian Akhir Semester mata kuliah Pemrograman Web Dasar.

Website ini menampilkan beberapa fitur seperti halaman beranda, kategori produk, detail produk, keranjang belanja, halaman transaksi, invoice pembelian, dan fitur cetak nota.

Teknologi yang Digunakan

  • HTML untuk struktur halaman website
  • CSS dan Tailwind CSS untuk tampilan
  • JavaScript dan jQuery untuk interaksi
  • Local Storage untuk simulasi penyimpanan keranjang
